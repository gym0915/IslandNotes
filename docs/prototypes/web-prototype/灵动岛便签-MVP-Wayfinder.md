# 灵动岛便签 MVP｜Wayfinder 讨论记录

> 状态：地图筹备中。本文只记录本次对话中明确确认的内容，不引用项目内已有资料。

## Destination

形成一份可直接交给设计与开发的 MVP 产品规格，明确用户如何创建便签、哪些便签出现在灵动岛、何时出现、如何切换与消失，以及首版明确不做什么。

## 已确认的决策

### 产品核心体验

用户对当前便签执行“挂起”，显式启动一次有系统时限的 Live Activity 展示会话，在会话期间可以从系统界面快速查看；它不是到了特定时间才出现的提醒通知，也不是永久常驻承诺。

### 同时挂起的便签数量

同一时间只允许挂起一条便签，且它必须是工作台中的当前便签。

### 创建与编辑边界

便签只在 App 内创建、编辑和管理。灵动岛负责快速查看，不承担输入或编辑。

### 便签内容结构

每条便签是一段纯文字，不区分标题和正文。

### 灵动岛展示层级

- 紧凑态不露出便签文字，只显示能够识别该 App 或挂起状态的视觉标记。
- 用户长按进入展开态后，才显示挂起便签的文字。
- 展开态空间不足时允许截断文字。

### 从灵动岛进入 App

- 轻点紧凑态，直接进入 App 的当前便签工作台。
- 长按只负责把灵动岛切换到展开态。
- 灵动岛展开后再次轻点，仍然进入当前便签工作台。

### 挂起操作边界

- “挂起”和“取消挂起”只在 App 的当前便签工作台中操作。
- 灵动岛的紧凑态与展开态均不提供快捷操作按钮，只负责查看和进入工作台。
- 便签不是待办任务，产品中不提供“完成”按钮或“已完成”状态。

### 挂起生命周期

- “挂起”是用户在 App 中对当前便签执行的一次显式动作；该动作启动一段 Live Activity 展示会话。
- 每段展示会话最长 8 小时，并可能因用户移除、用户禁用 Live Activities 或系统限制而提前结束。
- 展示会话结束后，当前便签不再处于“挂起中”；挂起不表示长期保留的用户意图，也不承诺永久常驻。
- 当前便签的身份和内容由 App 长期保留；Live Activity 只是它的短期系统投影。展示结束不会删除、入库或替换当前便签，也不会使内容丢失。
- Live Activity 达到 8 小时上限后，这次展示会话结束，当前便签进入“未挂起”状态；App 不保留“已到期”这一长期第三状态，也不保留挂起意图。便签内容完整保留。
- 产品状态以 Live Activity 是否活跃为准：活动活跃时是“挂起中”，活动结束时立即是“未挂起”。会话结束时，产品意图是同时结束 Dynamic Island 与 Lock Screen 展示，不主动保留或利用 Lock Screen 尾部。
- 系统仍可能在 Lock Screen 暂时保留已结束内容，最多 4 小时；产品不承诺系统界面绝对即时消失。此类系统残留不构成独立产品状态，不能称为“挂起中”，也不改变 App 中当前便签的“未挂起”状态。
- MVP 不提供定时提醒、定时挂起或倒计时；再次挂起边界仍在[重新定义 Live Activity 的挂起生命周期](../../decisions/tickets/06-session-lifecycle.md)中继续确认。

### 当前便签与旧便签

- App 的主要界面只关注当前便签，不在首页同时陈列历史便签。
- 旧便签需要保留，但应退居次要位置，避免干扰用户对当前便签的关注。

### App 页面结构

- 主页面采用“当前便签工作台”，只展示和操作当前便签。
- 主页面提供明确的“便签库”入口。
- “便签库”是次级页面，用于查看旧便签，并允许用户选择旧便签重新作为当前便签。
- App 中没有“新建便签”功能或按钮。

### 从便签库恢复旧便签

- 从便签库选中旧便签后，它只成为工作台中的当前便签。
- “设为当前”与“挂到灵动岛”是两个独立动作。
- 恢复旧便签不会自动把它挂到灵动岛；挂起仍需用户在工作台明确操作。
- 当前便签已有内容时，从便签库恢复旧便签采用“交换”规则：现有当前便签自动进入便签库，被选中的旧便签离开便签库并进入工作台。
- 交换前若现有当前便签正在挂起，应先取消挂起。
- 如果现有当前便签为空，则不把空白内容放入便签库，只让选中的旧便签进入工作台。

### 便签库的能力边界

- 便签库只用于浏览和恢复旧便签。
- 旧便签不能直接在便签库中编辑，也不能直接从便签库挂到灵动岛。
- 用户必须先将旧便签恢复为当前便签，才能编辑或挂起。
- 点击便签库中的旧便签时立即执行交换，不经过只读预览页，也不要求再次确认。
- MVP 不提供“设为当前便签”按钮；点击旧便签本身就是设为当前的操作。
- 便签库不提供删除入口；需要删除旧便签时，用户先点击它与当前便签交换，再回到主界面删除。

### 便签库排序

- 旧便签按照最近放入便签库的时间倒序排列，最近入库的显示在最上方。
- 交换时进入便签库的原当前便签，成为新的最近入库项并显示在顶部。
- MVP 不提供搜索、标签、文件夹、收藏或手动置顶；便签库保持为简单列表。

### 单一焦点约束

- 工作台中的当前便签与灵动岛上的挂起便签不能是两条不同的便签。
- 当前便签可以处于“展示会话活跃（挂起中）”或“没有活跃展示会话（未挂起）”状态；挂起状态属于短期展示会话，不属于便签的长期身份。
- 用户切换当前便签时，原当前便签如果正在挂起，会先自动取消挂起。
- 新的当前便签不会自动挂起。
- 因此，当前便签的 Live Activity 展示会话活跃时，其系统展示内容永远对应工作台中的同一条当前便签。

### 当前便签生命周期

- App 首次安装并打开时，首页直接呈现一个内容为空、可以立即编辑的当前便签。
- 当前便签支持编辑、挂起、取消挂起、放入便签库和删除。
- 用户将当前便签放入便签库后，其内容被保留，首页随即恢复为一个新的空白当前便签。
- 用户删除当前便签后，其内容不再保留，首页随即恢复为一个新的空白当前便签。
- 若当前便签的展示会话仍活跃，将它放入便签库或删除时，应同时结束该展示会话。
- 空白当前便签由系统自然补位，不需要用户执行“新建”操作。

### 当前便签编辑方式

- 首页展示的当前便签本身就是文本编辑器，不存在单独的“编辑入口”或“编辑”按钮。
- 用户轻点便签的文字区域即可直接输入或修改内容。
- 当前便签不区分查看态与编辑态。
- 编辑内容自动保存，不设置“保存”按钮；用户离开 App 或执行挂起操作时无需额外确认。
- 当前便签的展示会话活跃时，修改内容会自动同步到该 Live Activity，不需要先结束会话再重新挂起。
- 为避免输入过程中频繁刷新，灵动岛可以在用户短暂停止输入后更新。
- 便签支持多行纯文字和手动换行。
- 虚拟键盘右下角按键是换行键，不作为“完成”按钮，也不用于提交便签。
- App 内完整保留用户输入的换行；灵动岛展开态尽量按原换行显示，空间不足时截断。

### 便签长度上限

- 每条便签最多包含 240 个字符。
- 按用户感知到的字符计数：汉字、英文字母、数字、标点、空格和换行各计 1 个字符。
- 一个完整显示的 Emoji 计 1 个字符，即使它在底层由多个编码组合而成。
- 编辑器通过圆形进度表达已经使用的字符容量，不持续显示 `当前字符数 / 240` 文本。
- 圆形进度默认只显示逐渐填满的圆环，不在圆环内持续显示数字。
- 点击圆环后，临时显示“已输入”和“还可输入”的具体字符数。
- VoiceOver 朗读已输入字符数、240 字符上限和剩余可输入字符数。
- 达到 240 个字符后停止接受新字符，但仍允许用户删除或修改已有内容。
- 粘贴内容导致超限时，只保留能够容纳到 240 个字符的部分。
- 发生超限输入或粘贴时，轻量提示“最多 240 个字符”。

### 空白便签的操作限制

- 内容为空或只有空白字符时，不能挂起，也不能放入便签库。
- 空白便签不需要执行删除操作。
- 空白状态仍保留文本编辑器和进入便签库的入口。
- 输入有效文字后，挂起、放入便签库和删除操作才可用。

### 删除当前便签

- 删除属于不可恢复操作，执行前必须二次确认。
- 确认文案需要明确说明便签删除后无法恢复。
- 如果当前便签正在挂起，确认删除时同步结束灵动岛上的挂起状态。
- 删除完成后，首页立即恢复为新的空白当前便签。

### 数据保存边界

- MVP 的当前便签与便签库数据只保存在本机。
- MVP 不要求用户注册或登录。
- MVP 不接入 iCloud，也不提供跨设备同步。

### 支持设备范围

- MVP 只正式支持带有灵动岛的 iPhone。
- MVP 不为没有灵动岛的 iPhone 设计锁屏通知、普通通知或其他替代体验。
- 最低 iOS 版本及具体兼容设备清单等待技术验证后确定。
- MVP 不提供桌面小组件、锁屏小组件、分享扩展、快捷指令或其他 App 的分享入口。
- 系统层展示只包括灵动岛，以及挂起后由同一活动呈现的锁屏内容。

### 锁屏内容展示

- 设备锁定时，锁屏界面需要显示挂起便签的文字内容。
- 锁屏展示的内容与灵动岛展开态一致。
- 锁屏空间不足时允许截断文字。
- MVP 不对锁屏便签内容进行额外隐藏或模糊处理。

### 首次启动体验

- MVP 不提供独立的新手引导页，首次打开直接进入空白当前便签编辑器。
- 空白便签内提供一句浅色提示，暂以“输入想随时看到的内容，再挂到灵动岛”为意图示例。
- 浅色提示的正式文案不在当前阶段锁定，进入正式设计与开发时再修改。
- 首次点击“挂起”时，再按系统实际需要处理授权或失败说明。

### 视觉自定义边界

- MVP 使用一套统一视觉，并适配系统浅色模式与深色模式。
- MVP 不提供便签颜色、字体、字号或主题自定义。

## 领域词汇

### 挂起便签

当前存在活跃 Live Activity 展示会话的那一条当前便签。“挂起便签”只描述短期展示会话活跃期间的产品状态，不表示便签永久常驻或长期保留挂起意图；任意时刻最多存在一条挂起便签。

### Live Activity 展示会话

用户对当前便签执行一次“挂起”后启动的短期系统投影。每段会话最长 8 小时，并可能提前结束；会话结束不改变便签的长期身份或内容。

### 紧凑态

灵动岛未被用户长按展开时的日常显示状态，对应用户提供截图中的状态。

### 展开态

用户长按灵动岛后出现的较大展示状态，用于查看挂起便签的文字；文字可能因空间限制而被截断。

### 当前便签槽位

首页始终存在的唯一编辑位置。它可以承载一条当前便签；当内容被放入便签库或删除后，该位置自动恢复为空白。
