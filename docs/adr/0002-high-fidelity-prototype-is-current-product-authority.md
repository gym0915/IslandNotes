# 最新高保真原型是当前产品权威来源

`docs/prototypes/island-notes-ios-prototype.png` 不只是视觉参考，而是当前产品范围、界面状态、交互意图和设计系统的最高权威输入。它与 `docs/product/mvp-spec.md`、现有实现或现有测试发生冲突时，以最新 PNG 为准；旧规格、代码和测试仅作为上一版行为与迁移风险的证据。PNG 没有表达清楚的行为不能从旧原型中补齐，也不能仅凭高保真画面臆测，必须在本次访谈中明确后才能进入新版 Spec。

本次访谈中用户明确确认的修订是对 PNG 的权威补充，并在具体冲突上优先，例如 `Done` 才提交编辑草稿、Dynamic Island Expanded 也显示圆点列表、Library 替换可丢弃未提交草稿，以及 Support 占位行点击无动作。PNG 后续在同一路径更新时，新画面取代此前版本；已经明确确认的产品决定仍保留，除非用户再次修改。
