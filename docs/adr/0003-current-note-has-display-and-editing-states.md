# 当前便签区分展示态与显式提交的编辑态

当前便签默认以渲染内容呈现；进入编辑态时，以已保存源文本为起点创建只在内存中的编辑草稿。输入过程不写入 SwiftData，也不更新 Live Activity；用户点击 `Done` 后才提交草稿，保存成功才回到展示态并在需要时更新 Live Activity，保存失败则保留草稿并停留在编辑态。未提交草稿允许在 App 进程被终止时丢失。该决定取代上一版的常驻编辑器与自动保存契约，并避免渲染结果或未提交草稿成为第二份持久正文。

编辑会话可跨 Settings 或 Note Library sheet 呈现以及普通后台切换继续存在；打开或关闭这些界面不会隐式保存或丢弃草稿，返回后仍处于同一编辑态。只要 App 进程仍存活就保留草稿，进程终止时仍允许丢失。

Note Library 的替换按钮是一个明确例外：编辑草稿存在时按钮仍可点击，执行替换会直接丢弃未提交草稿，不自动提交也不显示二次确认。无损交换只保护已经提交的当前便签内容。
