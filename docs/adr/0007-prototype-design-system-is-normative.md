# 高保真原型的 Design System 是规范

最新 PNG 中的语义颜色、字体角色、4/8/16/24/32 间距尺度、14/22/34/pill 圆角、材质与阴影、44pt 最小触控目标、160–210ms 动效、Reduce Motion 降级、Live 绿色使用规则，以及组件明确展示的尺寸、状态和层级，均是本次实现与验收的规范性要求，而非近似视觉参考。仅当安全区、Dynamic Type、VoiceOver、系统键盘、系统 sheet 或 ActivityKit 托管布局要求冲突时允许必要自适应；因此实现需要集中 design tokens、可复用视觉组件和覆盖关键状态的视觉验证，而不能在业务视图中散落近似常量。
