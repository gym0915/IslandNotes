# 便签库通过明确按钮执行无损替换

Note Library 的每条便签使用最新 PNG 已补齐的行尾圆形回转箭头按钮执行“替换当前便签”，点击整行本身不执行替换。执行后，所选库中便签成为当前便签；原当前便签有内容时原子地进入便签库顶部，为空时移除空白记录，而不是被覆盖或删除。按钮使用 Lucide 风格图标，视觉无文字，但无障碍名称表达 `Replace current note`；成功后关闭 Note Library sheet 并回到 Workbench。

这里的无损只覆盖已提交内容。若 Workbench 正处于编辑态且存在未提交草稿，替换按钮仍可点击并直接执行交换；该草稿被静默丢弃，不自动保存，也不增加确认对话框。
